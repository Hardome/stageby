# Часть 1. Временный список и просмотр объекта (§3.5)

При реализации отмечать завершённые пункты `[x]`. Доступ — только руководителю.

## Временный список — отдельный удаляемый блок

- [x] Добавить самостоятельный компонент временного списка объектов на главной.
- [x] Использовать сгенерированный запрос и ссылки на `/projects/$projectId`.
- [x] Добавить пагинацию в URL, загрузку, ошибку с повтором и пустой результат.
- [x] Сохранить кнопку создания объекта.
- [x] Пометить блок в коде как временный: удалить после реализации дашборда.
- [x] Изолировать список от просмотра и редактора: удаляется компонент, подключение и его тесты.

## Просмотр объекта

- [x] Добавить `/projects/$projectId`, проверку ID до запроса и доступ руководителя.
- [x] Загружать объект и включённые этапы сгенерированными запросами; обработать загрузку, ошибки, отсутствие объекта и доступа.
- [x] Показать клиента, адрес, координаты, ссылку на карту и сроки проекта.
- [x] Открывать PDF проекта через авторизованный файловый API.
- [x] Показать серверные финансовые итоги работ, материалов и общий итог; различать null и ноль.
- [x] Показать этапы по порядку: статус, даты, мастер, прогресс, материалы и планы/факты.
- [x] Отображать отсутствующие даты по ТЗ и просрочку по времени Екатеринбурга.
- [x] По уточнению пользователя убрать кнопки «На главную» и «Обновить»; кнопку редактирования подключить в части 2.
- [x] Переработать компоновку: компактная шапка, финансовая сводка рядом с документами, сетка этапов и контрастные статусы.
- [x] Не добавлять ссылки на нереализованные страницы этапа, чек-листа и материалов.

## Проверки

- [x] Проверить список, пагинацию, переход, пустые состояния и ошибки запросов.
- [x] Проверить неверный ID, 404, доступ мастера, nullable-планы, даты и открытие PDF.
- [x] Проверить обе темы и ширины 390, 768, 1024 и 1440 px.
- [x] Запустить Biome, ESLint, Stylelint, Steiger, TypeScript, Vitest и сборку web.

API и схемы остаются действующими. Дашборд и рабочие действия внутри этапа не входят в эту часть.

## Результаты проверки

- Vitest: 178 тестов, 22 файла, все проходят.
- TypeScript, ESLint, Stylelint, Steiger и cspell проходят.
- Production-сборка Vite проходит.
- Biome проходит для всех изменённых исходников. Общая проверка web сообщает о форматировании существующих файлов с CRLF; сторонние файлы не переформатированы.
- В браузере проверены список и просмотр в обеих темах на 390, 768, 1024 и 1440 px; горизонтального переполнения нет. Проверка выполнена с подставленными ответами API, без изменения прикладных данных.
- Редактирование остаётся во второй части; кнопка будет подключена вместе с редактором.
