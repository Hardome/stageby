Зависимость: завершён [план редактирования объекта](frontend-project-edit.md), доступны форма редактирования и атомарное сохранение. Отмечать выполненное `[x]`.

## Добавление и восстановление

- [x] На последнем экране добавить единственный «Дополнительный этап» с фиксированным названием и пустым чек-листом.
- [x] Восстанавливать ранее исключённый дополнительный этап по ID; повторное добавление блокировать.
- [x] Разрешить добавление дополнительного этапа к завершённому объекту.
- [x] Использовать общие поля этапа и редактор чек-листа; перед сохранением требовать минимум один пункт у включённого этапа.

## Атомарное сохранение

- [x] Передавать новый этап через additionalStage в одном частичном PATCH через useUpdateProject вместе с остальными изменениями формы и версиями ресурсов.
- [x] При восстановлении сохранять ID и историю существующего этапа.
- [x] Подключить обработку ошибок полей, конфликтов версий, сохранение ввода и защиту от двойного сохранения из формы редактирования.

- [x] После сохранения обновить кэш объекта, инвалидировать редактор, списки, затронутые чек-листы и дашборд; вернуться на просмотр и показать уведомление об успехе.

## Результаты проверок (13.10.2026)

- Реализация использует существующий редактор объекта, общие поля этапа и чек-лист. Новый этап уходит через `additionalStage`, восстановление — через `stages` с прежним ID и версиями.
- Vitest: полный набор — 239 тестов; после добавления проверки кэша и уточнения адаптивной кнопки набор редактора — 42 теста. Все прошли.
- ESLint, Stylelint, Steiger, TypeScript, cspell и сборка Vite прошли.
- Biome check изменённых файлов и Biome lint всего web прошли. Общий `biome check .` выявил CRLF вместо LF в 131 неизменённом файле рабочей копии (`core.autocrlf=true`); эти файлы не переписывались.
- В браузере с подменёнными ответами API проверены обе темы и ширины 390, 768, 1024 и 1440 px, перенос текста кнопки восстановления, чек-лист, возврат на просмотр и уведомление об успехе. Скриншоты сохранены во временной папке.
- Проверены границы слоёв, отдельные файлы компонентов, импорты в начале, логические отступы и лимит 200 строк.
