# API Guidelines

`api/` contains the Fastify server, Drizzle schema and migrations, and tests.

| Read when working on                                                        | Documentation                                                    |
| --------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Fastify modules, routes, repositories, or API module integration tests      | [API module guidelines](../docs/rules/api-modules-guidelines.md) |
| PostgreSQL or Drizzle schemas, database queries, constraints, or migrations | [Database guidelines](../docs/rules/database-guidelines.md)      |

For authentication, sessions, users, and their migrations, consult current code and Git history for implementation status and historical context.
