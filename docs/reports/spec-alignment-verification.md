# Проверка согласования ТЗ и реализации

Дата: 23.10.2026. Проверено рабочее дерево на базе `4dbe8f9`.
Окружение: Windows, Node.js 24.19.0, pnpm 12.6.0, локальные PostgreSQL 18.6 и MinIO.

## Изменения

Все DIF-01–DIF-20 согласованы пользователем. Правила сохранены в
[решениях](../decisions/edited-ver2-decisions.md#согласование-расхождений-от-23102026),
ТЗ, предметной модели и руководстве API. Функциональные чек-листы обновлены.

По DIF-18 клиент, сервер и OpenAPI используют десятичные пределы включительно:
PDF объекта — 50 000 000 байт, счёт — 10 000 000 байт, фото — 20 000 000 байт.
Серверные проверки загрузки и привязки используют общую политику размеров.
Остальные согласованные пункты сохраняют поведение приложения.

## Автоматизированные проверки

| Проверка | Результат |
| --- | --- |
| `pnpm run codegen` | Пройдена; контракт и клиент сгенерированы из исходников |
| Сборка контракта в `pnpm run check` | Пройдена |
| `pnpm --dir api run lint:biome:fix` | Пройдена |
| `pnpm --dir api run build` | Пройдена, включая проверку типов |
| `pnpm --dir api run test` | 24 файла, 232 теста пройдены |
| `pnpm --dir web run check` | Пройдена: линтеры, типы, 94 файла с 502 тестами, сборка |
| `git diff HEAD --check` | Пройдена |
| `pnpm run check` | Пройдена полностью: контракт, API, web и все 734 теста |

Граничные тесты проверяют ровно допустимый размер и превышение на один байт,
повторную проверку при завершении загрузки, привязку фото и счетов,
а также исходное и подготовленное фото. Сквозной API-тест проходит загрузку
в настоящий MinIO, счета, фото, приёмку и выплаты.

Все 44 замечания cspell устранены добавлением корректных технических терминов
и словоформ в общий словарь. Проверка орфографии API и документации проходит
для 147 файлов, проверка web — для 514 файлов, замечаний нет.

## Ограничения и очистка

Ручной регресс в браузере и на реальных Android/iPhone не проводился.
Проверка установки ярлыка, камеры и пользовательских сценариев на устройствах
остаётся необходимой для полной приёмки по
[функциональным чек-листам](../guides/regression/README.md).

По прямому указанию пользователя план удалён до ручной приёмки, ссылка из карты
документации убрана. Всё содержимое `docs/tmp` удалено; каталог оставлен пустым.
Коммит и публикация не выполнялись.
