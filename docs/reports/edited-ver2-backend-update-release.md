## Проверки критериев

в настоящем PostgreSQL. Пути в таблице указаны относительно `api/`.

## Контракт и поставка

Исходные OpenAPI-контракты согласованы с документацией. Общие планы объекта вычисляются
из ручных планов включённых этапов, факт — из выплат и отдельных сумм оплат счетов.
Сводка к дате использует ручной план работ этапов с окончанием не позже даты.

Форма редактирования загружается через `GET /projects/{projectId}/edit`.
`PATCH /projects/{projectId}` требует `expectedVersion`; вложенные изменения также передают
версии ресурсов. Отсутствие поля сохраняет значение, null очищает nullable-поле.
Новый дополнительный этап создаётся только при редактировании; исключённый восстанавливается.
Обновление требует миграции `0002_bent_power_pack.sql`, добавляющей версию проекта.

Для установки используется пустая БД. Перенос старых финансовых данных в поставку не входит.
Проверены серверные сценарии; навигация по экранам формы и клиентские черновики относятся
к реализации web. Сгенерированные файлы обновляются командой codegen.
