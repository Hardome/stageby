# Ярлык Stageby на главном экране

Откройте Stageby по обычному адресу сервиса через HTTPS. Для локальной проверки на компьютере подходит `localhost`; адрес компьютера в локальной сети по HTTP не даёт всех возможностей установки на телефоне.

## Android: Chrome

1. Откройте главную страницу Stageby в Chrome.
2. В меню браузера выберите «Добавить на главный экран». В зависимости от версии Chrome действие может называться «Установить приложение» или «Создать ярлык».
3. Подтвердите имя Stageby и добавление значка.
4. Запустите Stageby с главного экрана.

## iPhone и iPad: Safari

1. Откройте главную страницу Stageby в Safari.
2. Нажмите «Поделиться», затем «На экран Домой».
3. Если доступен переключатель «Открывать как веб-приложение», включите его.
4. Подтвердите добавление и запустите Stageby с главного экрана.

## Вход и переход к этапу

Основной ярлык открывает `/`. Действующая сессия определяет главную страницу: руководитель видит дашборд, мастер — «Мои этапы». Если браузер выделил установленному приложению отдельное хранилище или сессия истекла, войдите повторно. После входа сохраняется безопасная внутренняя ссылка на целевую страницу.

Отдельный ярлык на конкретный этап можно создать средствами браузера с открытой страницы этапа. Устанавливаемое приложение из manifest всегда запускается с `/`; отдельная ссылка зависит от возможностей браузера. Доступ к этапу проверяется сервером при каждом обращении.

## Работа с фотографиями

Для работы нужен интернет. Выбранные фотографии сохраняются в очереди на этом устройстве и в этом браузере; после обрыва связи откройте тот же пункт под тем же пользователем и повторите загрузку. Не закрывайте приложение до подтверждения загрузки: отправка при закрытом приложении не выполняется. Если браузер запрещает локальное хранилище, очередь доступна только до закрытия вкладки — приложение покажет предупреждение.

После явного выхода или смены пользователя очередь и черновики очищаются. Истечение сессии сохраняет их для повторного входа того же пользователя. Загруженная фотография сохраняется на сервере отдельно от явного выполнения пункта кнопкой «Готово».
