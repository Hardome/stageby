# Согласованные правила edited.ver2

Источник — [ТЗ edited.ver2](../plans/ТЗ%20на%20разработку%20страницы%20и%20сценарии%20edited.ver2.md).
Правила реализованы в [предметной модели](domain-model.md) и [API](api-contract.md).

| Решение | Правило |
| --- | --- |
| R1 | План денег строится по плановым суммам этапов, заканчивающихся к выбранной дате включительно. |
| R2 | Панель содержит таблицу и индикаторы. Счета принадлежат этапу; заявки на материалы оформляются вне системы. |
| R3 | Строка панели показывает первый включённый по позиции этап, который ещё не paid. |
| R4 | Объект завершён, когда все включённые этапы paid. |
| R5 | Невыполненный предшественник вызывает предупреждение, но не блокирует старт. |
| R6 | Материалы: красный при отсутствии счетов или открытой нехватке; жёлтый при неполной оплате/доставке; зелёный при полной оплате и доставке без нехватки. Подписи частичной оплаты и доставки независимы. |
| R7 | Нехватку отдельно закрывает руководитель. |
| R8 | Фото сохраняются при выходе; выполнение подтверждается отдельным действием «Готово». |
| R9 | Вход по логину и паролю; телефон необязателен. |
| R10 | Создание выполняется на отдельной странице с переходом на объект в той же вкладке. |
| R11 | Руководитель подтверждает paid после приёмки, когда план работ задан и остаток работ ≤ 0. |
| R12 | Факт денег равен внесённым выплатам и полностью оплаченным счетам того же финансового периметра. |
| R13 | Выплаты наличные, вносятся руководителем без документов. Получатель обязателен и сохраняется независимо от назначения мастера этапа. |
| R14 | Даты этапов вводятся вручную внутри срока проекта; пересечения разрешены. |
| R15 | Счета добавляются после создания объекта в существующий этап. |
| R16 | Удаление фото по сроку хранения сохраняет выполнение, прогресс и статус. Новое выполнение и доработка требуют нового фото. |
| R17 | Серверный календарь — Екатеринбург UTC+5; диапазон панели — сегодня…+30 дней включительно. Адаптивность и браузерные проверки выполняются по планам экранов. |
| R18 | Приёмка подтверждается руководителем без файла акта. |
