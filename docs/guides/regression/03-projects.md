# 03. Создание, просмотр и редактирование объектов

[Подготовка и фиксация результатов](README.md). Выполняет Р. Нужны несколько активных мастеров, валидные PDF и отдельные объекты для разрушающих сценариев. После каждого сохранения проверяйте результат обновлением страницы.

## Создание

- [ ] PRJ-01. Откройте создание → сначала реквизиты объекта, затем выбор этапов; стандартные этапы изначально выбраны, дополнительного этапа среди них нет.
- [ ] PRJ-02. Введите клиента, адрес, координаты и границы дат; на выборе оставьте один стандартный этап и сохраните → создан один объект с этим этапом, открывается дашборд. Подпись объекта состоит из клиента и адреса.
- [ ] PRJ-03. Создайте объект со всеми стандартными этапами, не открывая их индивидуальные экраны → все выбранные этапы сохранены с шаблонными пунктами, без заданных дат, мастера и планов.
- [ ] PRJ-04. Настройте этап, перейдите назад и вперёд, пропустите его экран → введённые данные сохраняются, пропуск не исключает этап.
- [ ] PRJ-05. Попробуйте убрать все этапы и оставить пустой чек-лист → сохранение запрещено; нужен хотя бы один этап и один пункт в каждом включённом этапе.
- [ ] PRJ-06. Проверьте пустые реквизиты, координаты за пределами широты/долготы, окончание раньше начала и даты этапа вне границ объекта → ошибки у соответствующих полей, переход/сохранение не скрывает ошибку.
- [ ] PRJ-07. Задайте этапу только начало, только окончание, обе даты; используйте границы проекта и пересекающиеся сроки соседних этапов → допустимые комбинации сохраняются, соседние этапы не переносятся автоматически.
- [ ] PRJ-08. Введите планы работ/материалов как пустое значение, 0 и положительную сумму → состояния различаются после сохранения. Отрицательные суммы отклоняются; суммы в рублях не меняются в 100 раз.
- [ ] PRJ-09. Добавьте, переименуйте и удалите пункты и подсказки → индивидуальный состав сохраняется; новый объект того же типа получает исходный шаблон, а не изменения предыдущего.
- [ ] PRJ-10. Выберите активного мастера; отключённый пользователь и руководитель не должны подменять допустимого активного мастера при назначении.
- [ ] PRJ-11. Нажмите сохранение дважды и повторите после потери ответа → объект и вложенные этапы не дублируются; при неопределённом результате сначала проверьте список, не создавайте новый запрос вручную.

## Документы и просмотр

- [ ] PRJ-12. Прикрепите несколько PDF, сохраните объект и откройте каждый документ → открывается соответствующий файл в сохранённом порядке.
- [ ] PRJ-13. Попробуйте не-PDF, пустой/повреждённый файл и PDF больше лимита; отдельно проверьте валидный файл на границе из README → недопустимый файл не привязывается, допустимый загружается.
- [ ] PRJ-14. Откройте карточку → видны реквизиты, включённые этапы, даты, мастера, планы/факты и документы. Подписи и суммы соответствуют одному объекту.
- [ ] PRJ-15. Как назначенный мастер откройте сам объект по прямой ссылке → общего объекта и его финансов нет; разрешённый контекст доступен через свой этап.

## Составное редактирование

- [ ] PRJ-16. Одним сохранением измените реквизиты, PDF, сроки, назначения и планы нескольких этапов → все изменения сохраняются вместе и отображаются в связанных экранах.
- [ ] PRJ-17. Одновременно расширьте срок объекта и перенесите этап в новую допустимую границу → сохранение проверяет итоговые даты. Недопустимая итоговая граница отклоняет весь запрос без частичных изменений.
- [ ] PRJ-18. До старта замените состав чек-листа → сохранён новый непустой состав. После фактического старта изменение состава недоступно, даже если снять все отметки выполнения.
- [ ] PRJ-19. На начатом/принятом/выплаченном этапе измените плановые даты, мастера и планы → разрешённые изменения сохраняются; фактические даты не переписываются, получатели старых выплат не меняются.
- [ ] PRJ-20. Исключите не начатый этап без фото, счетов и выплат → он исчезает из обычного списка, нумерации и финансов. В редакторе восстановите его → вернулась та же запись с прежними планами и чек-листом.
- [ ] PRJ-21. Попробуйте исключить последний включённый этап, начатый этап, этап с выплатой/счётом/фото; отдельно с уже удалённым фото → операция запрещена, состояние объекта не меняется частично.
- [ ] PRJ-22. Добавьте дополнительный этап с непустым индивидуальным чек-листом → он последний и существует в одном экземпляре. Исключите и восстановите его → новый дубль не появляется.
- [ ] PRJ-23. Удалите связь одного PDF и добавьте другой → состав документов после обновления соответствует сохранению; остальные документы не теряются.
- [ ] PRJ-24. Откройте редактор в двух вкладках, сохраните разные изменения → устаревшее сохранение сообщает о конфликте, не перетирает новые данные и сохраняет ввод для разбора.
- [ ] PRJ-25. Откройте архивный объект и попробуйте редактирование → изменения запрещены. При отказе сети форма не сообщает успех и не теряет ввод.
