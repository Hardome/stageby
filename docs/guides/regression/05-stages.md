# 05. «Мои этапы» и карточка этапа

[Подготовка и фиксация результатов](README.md). Нужны А, Б, Р, объект с несколькими этапами и более страницы назначений А.

## Список мастера

- [ ] STG-01. Как А откройте «Мои этапы» → видны только назначенные А включённые этапы, счётчик и пагинация не раскрывают чужие записи.
- [ ] STG-02. Откройте список мастера без назначений → корректное пустое состояние, без старых карточек другого пользователя.
- [ ] STG-03. Перейдите на следующую страницу, откройте этап, вернитесь назад и обновите браузер → позиция списка сохраняется, страницы не смешиваются.
- [ ] STG-04. Р переназначает этап с А на Б → у А он исчезает при следующем запросе, у Б появляется; открытая вкладка А не позволяет продолжить работу.
- [ ] STG-05. Сравните карточки списка с карточками этапов → статус, клиент/адрес, мастер и суммы согласованы после выплаты, доставки и выполнения пункта.

## Карточка и доступ

- [ ] STG-06. Откройте свой этап → видны название, номер среди включённых этапов, клиент, адрес, плановые даты, мастер и финансовый контекст этого этапа.
- [ ] STG-07. Откройте карту/координаты и телефон мастера, где они доступны → используются сохранённые координаты/номер; отсутствие необязательного телефона не ломает экран.
- [ ] STG-08. Как А откройте PDF проекта из своего этапа → файл доступен без получения общей карточки объекта. Прямой URL чужого этапа и его вложенного ресурса показывает нейтральную недоступность.
- [ ] STG-09. Проверьте переходы к чек-листу, фотографиям, выплатам и материалам; обновите прямые ссылки и переключите доступные вкладки → открыт нужный этап, параметры навигации не теряются.
- [ ] STG-10. Как мастер проверьте отсутствие действий изменения плана, назначения, выплат и приёмки; как Р проверьте доступность разрешённых действий.
- [ ] STG-11. Начните этап при невыполненном предыдущем включённом → есть предупреждение, старт разрешён. Если предыдущий принят (`completed`), ожидание полной выплаты не требуется; исключённый предшественник не блокирует.
- [ ] STG-12. У этапа нет обеих или одной плановой даты → экран не подставляет фиктивную дату, не падает и корректно показывает отсутствие значения.
- [ ] STG-13. Откройте архивный объект через этап → доступные сведения читаются, операции изменения недоступны. Исключённый этап не появляется в обычных списках.
- [ ] STG-14. Имитируйте медленную загрузку, ошибку и повтор → состояние загрузки отличается от отсутствующей записи, повтор загружает актуальный этап, сведения прошлого ID не показываются как новый этап.
