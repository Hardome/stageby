# 04. Дашборд руководителя

[Подготовка и фиксация результатов](README.md). Выполняет Р. Для финансов используйте контрольный набор Ф1/Ф2, для списков — больше страницы объектов, полностью выплаченный и архивный объекты.

## Строки и навигация

- [ ] DASH-01. Откройте главную → есть сводки работ, материалов и общего итога, счётчик активных объектов и список; мастер по прямой ссылке не получает данные руководителя.
- [ ] DASH-02. На объекте с несколькими этапами сравните строку с карточкой → выбран первый включённый по позиции этап, который ещё не `paid`; мастер, даты, индикаторы и суммы этапа относятся к нему.
- [ ] DASH-03. Выплатите последний этап раньше первого → строка всё ещё показывает первый невыплаченный, объект не завершён. Исключённый этап не становится текущим.
- [ ] DASH-04. Выплатите все включённые этапы → активный счётчик уменьшается. Добавьте дополнительный этап → объект снова активен и текущий этап обновляется.
- [ ] DASH-05. Сравните объекты с заданным началом текущего этапа и без начала → даты упорядочены, строки без начала и полностью выплаченные идут в конце. При одинаковых датах порядок стабилен после обновления.
- [ ] DASH-06. Подготовьте неназначенный этап с началом в пределах 7 дней и этап без начала → предупреждение применимо к первому и не появляется только из-за отсутствующей даты у второго.
- [ ] DASH-07. Откройте объект и этап из списка, вернитесь назад → выбранная дата и страница списка сохранены. Обновите URL со второй страницей → отображается та же страница без дублей.
- [ ] DASH-08. Подготовьте архивный объект → он не входит в список, активный счётчик и сводку. Пустая база показывает пустое состояние и нулевые суммы.

## Календарь и расчёты

- [ ] DASH-09. Выберите Т и Т+30 → расчёт доступен. Вчера, Т+31, невозможная дата и испорченный параметр URL не дают ошибочного расчёта или падения; календарь основан на Екатеринбурге.
- [ ] DASH-10. На наборе Ф1/Ф2 выберите Т → работы 10 000/3 000/7 000, материалы 6 000/4 000/2 000, итог 16 000/7 000/9 000.
- [ ] DASH-11. Выберите Т+2 → работы 30 000/5 000/25 000, материалы 14 000/4 000/10 000, итог 44 000/9 000/35 000. Будущая выплата Ф1 учитывается только с её даты.
- [ ] DASH-12. Уберите окончание у отдельного этапа → он не входит в расчёт по дате; добавьте просроченный этап → он входит накопительно. Статус `paid` сам по себе не исключает этап из финансов.
- [ ] DASH-13. У выбранного этапа очистите план работ → план и остаток работ неизвестны, общий план/остаток неизвестны, факт доступен. План этапа за пределами даты не портит полноту текущей сводки.
- [ ] DASH-14. Замените пустой план на 0 → это известный нулевой план. Создайте переплату → отрицательный остаток сохраняется, не обнуляется.
- [ ] DASH-15. Измените сумму выставления счёта без изменения оплаты → факт материалов не меняется. Измените фактическую оплату → факт меняется, ручной план остаётся прежним.
- [ ] DASH-16. Во время смены даты замедлите сеть → старые суммы не подписываются как уже рассчитанные на новую дату; после ответа значения и дата согласованы, повторные действия не создают гонку экранов.
- [ ] DASH-17. По очереди вызовите ошибку сводки и списка через тестовый отказ → исправный блок остаётся доступен, проблемный показывает ошибку и повтор; восстановление не сбрасывает остальные параметры.
