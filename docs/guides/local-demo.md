# Доступ с телефона и демонстрация через Quick Tunnel

Руководство для временного доступа к локальному Stageby через HTTPS: с сервером разработки либо с
готовой сборкой.

Все команды выполняйте из корня репозитория. Нужны подготовленное
[локальное окружение и первый руководитель](../../README.md#быстрый-старт), работающий Docker
Engine и `cloudflared` в `PATH`. Используйте тестовые данные и отдельные учётные записи: туннель
делает локальное приложение доступным из интернета.

## 1. Запустите инфраструктуру и туннели

```sh
pnpm run db:up
```

Команда запускает PostgreSQL и MinIO и дожидается готовности. После получения новых миграций
примените их через `pnpm --dir api run db:migrate`.

В двух отдельных терминалах запустите:

```sh
pnpm run tunnel
```

```sh
pnpm run tunnel:minio
```

Первый туннель направлен на приложение, порт 3000; второй — на S3 API MinIO, порт 9000. Оставьте оба
процесса работать и сохраните их разные ссылки `https://….trycloudflare.com`. До запуска приложения
первый адрес может возвращать ошибку. При перезапуске туннеля ссылка меняется; `Ctrl+C` его
останавливает.

## 2. Настройте адреса

В `api/.env` добавьте HTTPS-origin приложения в список разрешённых, а HTTPS-адрес MinIO укажите как
endpoint:

```dotenv
CORS_ORIGIN=http://localhost:3000,https://ваш-адрес-приложения.trycloudflare.com
S3_ENDPOINT=https://ваш-адрес-minio.trycloudflare.com
```

Адреса указывайте без завершающего `/`. Не подставляйте адрес MinIO вместо origin приложения.
Отдельный endpoint нужен, поскольку браузер загружает и скачивает файлы напрямую из S3 по
подписанным ссылкам.

При каждой смене ссылки обновите соответствующую переменную и перезапустите API. Эти изменения не
требуют повторной сборки приложения.

## 3. Выберите режим запуска

### Разработка с HMR

Сохраните `NODE_ENV=development` в `api/.env` и выполните:

```sh
pnpm run dev
```

Откройте HTTPS-ссылку приложения на телефоне. Vite перенаправляет запросы API; существующая конфигурация
разрешает домены `.trycloudflare.com`.

### Демонстрация готовой сборки

Остановите `pnpm run dev`, если он работает, чтобы освободить порты 3000 и 3001. Примените миграции
и соберите пакеты:

```sh
pnpm --dir api run db:migrate
pnpm --dir contracts run build
pnpm --dir api run build
pnpm --dir web run build
```

В `api/.env` установите `NODE_ENV=production`. В этом режиме обязательны `S3_ENDPOINT`,
`S3_REGION`, `S3_BUCKET`, `S3_ACCESS_KEY_ID` и `S3_SECRET_ACCESS_KEY`. Для локального MinIO
остальные значения оставьте из `api/.env.example`, включая `S3_CREATE_BUCKET=true` для
первоначального создания bucket. Эти локальные credentials не предназначены для внешнего production
S3.

В отдельном терминале запустите API:

```sh
pnpm --dir api run start
```

В другом терминале запустите раздачу собранного фронта:

```sh
pnpm --dir web run preview --host 127.0.0.1 --port 3000 --strictPort
```

`preview` использует прокси API и разрешённые домены из конфигурации Vite, отдаёт `dist/` без HMR.
`start` запускает собранный JavaScript и сам не устанавливает `NODE_ENV`. В production-режиме
cookie сессии имеет `Secure`: для входа открывайте HTTPS-ссылку приложения.

Во время демо работают Docker, API, Vite preview и оба туннеля. Изменения исходников требуют
повторной сборки соответствующего пакета; после повторной сборки API перезапустите `start`.

## 4. Проверьте доступ

- Войдите по ссылке приложения под созданным руководителем.
- Откройте объект и этап, загрузите фото или PDF и откройте загруженный файл с телефона.
- Для камеры, HEIC и ярлыка используйте [мобильные проверки регресса](regression/11-cross-functional.md) и [инструкцию установки ярлыка](install-shortcut.md).

| Симптом | Что проверить |
| --- | --- |
| «Источник запроса не разрешён» | Текущий origin приложения есть в `CORS_ORIGIN`, API перезапущен |
| Не загружаются или не открываются файлы | MinIO и его туннель работают, `S3_ENDPOINT` содержит актуальную HTTPS-ссылку; получите новую ссылку на файл через приложение |
| API сообщает `ECONNREFUSED 127.0.0.1:9000` | Docker и MinIO запущены; выполните `pnpm run db:up`, проверьте endpoint |
| Занят порт 3000 или 3001 | Остановлены предыдущие процессы разработки/демо |
| Вход не сохраняется на локальном HTTP | Верните `NODE_ENV=development` либо используйте HTTPS-туннель |

## 5. Вернитесь к локальной разработке

Остановите процессы приложения и оба туннеля через `Ctrl+C`. Восстановите в `api/.env`:

```dotenv
NODE_ENV=development
CORS_ORIGIN=http://localhost:3000
S3_ENDPOINT=http://127.0.0.1:9000
```

Запустите `pnpm run dev`. Если инфраструктура больше не нужна, выполните `pnpm run db:down`.
