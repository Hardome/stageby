# Stageby

Stageby — приложение для планирования и контроля поэтапного строительства. Репозиторий объединяет серверное API, веб-интерфейс и общий OpenAPI-контракт.

## Стек

- API: Fastify, TypeScript, Zod, Drizzle ORM и PostgreSQL.
- Web: React, Vite, TanStack Router, TanStack Query и Tailwind CSS.
- Контракт: OpenAPI 3.1 с генерацией серверных типов и клиентского кода.

## Быстрый старт

Для локальной разработки понадобятся:

- Node.js 24.7 или новее;
- pnpm 11 или новее;
- Docker с запущенным Docker Engine и поддержкой Compose.

Подготовьте проект одной командой из корня репозитория:

```sh
pnpm run bootstrap
```

Команда:

1. создаст `api/.env` и `web/.env` из файлов-примеров, если их ещё нет;
2. установит зависимости контрактов, API и веб-приложения;
3. проверит OpenAPI-контракт, сгенерирует код и дерево маршрутов;
4. запустит PostgreSQL;
5. применит миграции базы данных.

Существующие `.env` не перезаписываются.

После подготовки запустите оба приложения:

```sh
pnpm run dev
```

Для доступа к приложению через Cloudflare Quick Tunnel установите `cloudflared` и добавьте его в `PATH`. При работающем `pnpm run dev` откройте второй терминал и выполните:

```sh
pnpm run tunnel
```

Команда выведет публичную ссылку `https://….trycloudflare.com`, через которую доступны веб-приложение и API через прокси Vite. Туннель работает, пока открыта команда; `Ctrl+C` останавливает его. При повторном запуске создаётся новая ссылка.

Добавьте полученный адрес без завершающего `/` в `CORS_ORIGIN` файла `api/.env`, сохранив локальный адрес:

```dotenv
CORS_ORIGIN=http://localhost:3000,https://ваш-адрес.trycloudflare.com
```

Перезапустите `pnpm run dev`, оставив туннель работать. При смене ссылки обновите `CORS_ORIGIN` и снова перезапустите приложение. Без этого API отклоняет изменяющие запросы с сообщением «Источник запроса не разрешён.».

Для загрузки и скачивания файлов с других устройств запустите отдельный туннель к работающему MinIO в ещё одном терминале:

```sh
pnpm run tunnel:minio
```

Полученный адрес туннеля MinIO без завершающего `/` укажите в `api/.env`:

```dotenv
S3_ENDPOINT=https://ваш-адрес-minio.trycloudflare.com
```

Перезапустите `pnpm run dev`, оставив оба туннеля работать. В `CORS_ORIGIN` сохраняйте адрес туннеля приложения. При смене ссылки MinIO обновите `S3_ENDPOINT` и перезапустите приложение. После остановки туннеля для локальной работы верните `S3_ENDPOINT=http://127.0.0.1:9000` и перезапустите приложение.

Для полной проверки контрактов, линтеров, типов, тестов и сборок выполните из корня:

```sh
pnpm run check
```

Интеграционные тесты API требуют запущенный PostgreSQL (`pnpm run db:up`) и применённые миграции (`pnpm --dir api run db:migrate`). Команда использует существующие `lint`, `typecheck`, `test` и `build`; линтеры могут автоматически исправить файлы.

Доступные адреса:

| Сервис | Адрес |
| --- | --- |
| Веб-приложение | [http://localhost:3000](http://localhost:3000) |
| API | [http://127.0.0.1:3001](http://127.0.0.1:3001) |
| Swagger UI | [http://127.0.0.1:3001/documentation](http://127.0.0.1:3001/documentation) |

В режиме разработки Vite перенаправляет запросы `/auth` и `/users` в API. Адрес сервера для прокси задаётся переменной `API_PROXY_TARGET` в `web/.env`.

## Демо на продакшен-сборке через Quick Tunnel

Все команды выполняйте из корня репозитория. Для первого запуска подготовьте проект через `pnpm run bootstrap`, как описано выше. Установите `cloudflared` и добавьте его в `PATH`.

### 1. Запустите инфраструктуру и соберите приложения

Откройте Docker Desktop и дождитесь готовности Docker Engine. Затем выполните:

```sh
pnpm run db:up
pnpm --dir api run db:migrate
pnpm --dir contracts run build
pnpm --dir api run build
pnpm --dir web run build
```

`db:up` запускает PostgreSQL и MinIO и дожидается их готовности. Ошибка API `ECONNREFUSED 127.0.0.1:9000` означает, что MinIO недоступен: проверьте Docker Desktop и повторите `pnpm run db:up`.

### 2. Запустите туннели

В отдельном терминале запустите туннель приложения:

```sh
pnpm run tunnel
```

В ещё одном терминале запустите туннель MinIO для загрузки и скачивания файлов с других устройств:

```sh
pnpm run tunnel:minio
```

Оставьте оба процесса работать и сохраните выданные HTTPS-ссылки. До запуска веб-приложения ссылка первого туннеля может возвращать ошибку — это ожидаемо.

### 3. Настройте API

В `api/.env` добавьте адрес туннеля приложения в `CORS_ORIGIN`, а адрес туннеля MinIO укажите в `S3_ENDPOINT`. Адреса указывайте без завершающего `/`:

```dotenv
CORS_ORIGIN=http://localhost:3000,https://ваш-адрес.trycloudflare.com
S3_ENDPOINT=https://ваш-адрес-minio.trycloudflare.com
```

Для продакшен-режима API также установите `NODE_ENV=production`. В этом режиме обязательны `S3_ENDPOINT`, `S3_REGION`, `S3_BUCKET`, `S3_ACCESS_KEY_ID` и `S3_SECRET_ACCESS_KEY`; для локального MinIO остальные значения можно сохранить из `api/.env.example`. Сохраните `S3_CREATE_BUCKET=true`, чтобы API мог создать bucket при первом запуске.

Команда `start` запускает собранный JavaScript, но сама не устанавливает `NODE_ENV`. При `NODE_ENV=production` cookie сессии имеет флаг `Secure`, поэтому для входа используйте HTTPS-ссылку туннеля.

### 4. Запустите API и веб-приложение

В отдельном терминале запустите API:

```sh
pnpm --dir api run start
```

В другом терминале запустите веб-приложение:

```sh
pnpm --dir web run preview --host 127.0.0.1 --port 3000 --strictPort
```

Перед запуском освободите порт 3000, остановив `pnpm run dev`, если он работает. `preview` отдаёт готовую продакшен-сборку без HMR и использует существующие настройки прокси API и разрешённых доменов `.trycloudflare.com`. Менять `web/vite.config.ts` не требуется.

Откройте HTTPS-ссылку туннеля приложения и используйте её для демонстрации. Во время демо должны работать Docker, API, веб-приложение и оба туннеля. Изменения исходников требуют повторной сборки соответствующего приложения; после пересборки API перезапустите `start`.

### 5. Завершите демо

Остановите API, `preview` и оба туннеля через `Ctrl+C`. После перезапуска Quick Tunnel выдаёт новую ссылку: обновите соответствующие адреса в `api/.env` и перезапустите API. Изменения только этих настроек не требуют пересборки.

Для возвращения к локальной разработке восстановите в `api/.env`:

```dotenv
NODE_ENV=development
CORS_ORIGIN=http://localhost:3000
S3_ENDPOINT=http://127.0.0.1:9000
```

Затем запустите `pnpm run dev`. Если контейнеры больше не нужны, остановите их командой `pnpm run db:down`.

## Команды из корня

| Команда | Назначение |
| --- | --- |
| `pnpm run bootstrap` | Полностью подготовить локальное окружение |
| `pnpm run dev` | Одновременно запустить API и веб-приложение |
| `pnpm run tunnel` | Запустить Cloudflare Quick Tunnel к приложению на порту 3000 |
| `pnpm run tunnel:minio` | Запустить Cloudflare Quick Tunnel к MinIO на порту 9000 |
| `pnpm run db:up` | Запустить PostgreSQL и MinIO и дождаться готовности |
| `pnpm run db:down` | Остановить контейнеры проекта |
| `pnpm run db:logs` | Показать логи PostgreSQL и MinIO |

Команды сборки, тестирования, проверки и генерации кода описаны в README отдельных приложений:

- [API](api/README.md)
- [Web](web/README.md)
- [Контракты](contracts/README.md)

## Структура репозитория

```text
stageby/
├── api/         # Fastify API, схема БД и миграции
├── contracts/   # общий OpenAPI-контракт
├── docs/        # правила, руководства, решения, отчёты и текущие планы
├── scripts/     # служебные скрипты проекта
├── web/         # React-приложение
└── compose.yaml # локальные PostgreSQL и MinIO
```

## Работа с контрактом

Источник истины для HTTP API — `contracts/references/stageby/stageby.yaml`, который объединяет маршруты сущностей из `contracts/references/`. Реализованы авторизация, пользователи, объекты, этапы и чек-листы, файлы, выплаты, материалы и панель руководителя. Redocly проверяет исходники и собирает `contracts/openapi.yaml`, который читают приложения. После изменения контракта соберите его и обновите сгенерированный код обоих приложений:

```sh
pnpm run codegen
```

Команда обновляет `contracts/openapi.yaml` и сгенерированный код API и web. Собранный `openapi.yaml` хранится в Git и вручную не редактируется. Подробности — в [руководстве по контрактам](contracts/README.md).

Файлы в `api/src/generated` и `web/src/generated` вручную не редактируются.
